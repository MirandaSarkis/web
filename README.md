# mirandasarkis.com

Web de Miranda Sarkis, artista visual.

- `contenido/`: todo el material de la web (fotos, fichas y textos). Ver **[COMO-USAR.md](COMO-USAR.md)**.
- `sitio/`: la plantilla y el programa que arma la web (`construir.py`).
- `.github/workflows/publicar.yml`: publica la web en GitHub Pages con cada cambio.
